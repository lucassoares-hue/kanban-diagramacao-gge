# Kanban Diagramação GGE

Kanban visual para o fluxo de trabalho diário da equipe de diagramação do GGE.

## Visão geral

- **Frontend (Kanban)**: ferramenta visual de uso diário da equipe, onde as demandas são organizadas e movidas entre colunas (status).
- **Google Sheets**: base de dados usada para registrar e medir a produtividade da equipe.
- **Google Apps Script**: camada de integração entre o Kanban (frontend) e o Google Sheets (banco de dados).

## Estrutura do projeto

```
kanban-diagramacao-gge/
├── frontend/        Interface visual do Kanban (HTML/CSS/JS)
├── apps-script/      Scripts de integração com Google Sheets
└── docs/             Documentação do projeto
```
